MINECRAFT JAVA 26.2–26.3 – RESOURCE-PACK „Light 0“
===================================================

Dieses Pack ersetzt die Optik der Akazien-Falltür durch das enthaltene Custom-Modell.
Es betrifft alle Ausrichtungen sowie die offenen und geschlossenen Zustände. Das
Modell wird aus assets/minecraft/models/block/acacia_trapdoor_custom.json geladen.

VERSIONEN
---------
pack.mcmeta deklariert die Resource-Pack-Formate 88.0 bis 97.1 (Minecraft 26.2
bis 26.3).

MODELL UND TEXTUREN
-------------------
Das Blockbench-Modell liegt hier:
  assets/minecraft/models/block/acacia_trapdoor_custom.json

Die Texturen liegen in:
  assets/minecraft/textures/block/

Wenn du das Modell ersetzt, exportiere es als „Minecraft Java Block/Item Model“
und achte darauf, dass die Textur-Verweise in der JSON-Datei zu den PNG-Dateien
in diesem Ordner passen.

INSTALLATION
------------
Lasse pack.mcmeta und den Ordner assets direkt im Hauptordner des Packs. Für ein
ZIP muss der Inhalt dieses Ordners direkt im ZIP-Root liegen.

Hinweis: Das Pack ändert die Optik der Akazien-Falltür. Verhalten und Hitbox
bleiben die der Vanilla-Falltür. Der Light-Block wird nicht mehr geändert.
